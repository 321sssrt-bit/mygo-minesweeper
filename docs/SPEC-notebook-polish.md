# MyGO!!!!! 迷子扫雷 — 「灯的笔记本」美术打磨与曲目阶梯规格

术语见 [GLOSSARY.md](../GLOSSARY.md)；美术定调的理由见 [ADR 0001](adr/0001-notebook-art-direction.md)。

## Problem Statement

项目梗足而打磨不足：

1. **没有美术定调**：夜间是开发者仪表盘式的 slate 深海军蓝，日间只是框架默认主题；`main.go` / `board.go` 有 66 处硬编码颜色绕过主题。
2. **成员颜色三套互相矛盾**：`Member.ColorHex`、`numberColor`、头像（按名字哈希取色，灯是粉色、爱音是蓝色）各不相同，且都偏离官方代表色。
3. **口吻不是 MyGO**：游戏内写着 `egoist/mygo Native UI`，README 首屏是图形 API 清单；与作品「迷子」的基调脱节。
4. **曲目阶梯断裂**：无技能求解器模拟下通关率 95% → 81% → 24%（春日影 30×16）→ 44%（诗超绊 20×20，反弹）→ 直接跳到 1,000,000 格的决斗。
5. **图标与 README 素材**是通用果冻三消风，看不出 MyGO。

## Solution

以作品简介为锚，把美术定为「灯的笔记本」，统一颜色来源，去掉技术口吻，并把曲目重排成平滑的七首阶梯。玩法机制、技能与平衡冻结，留给之后的玩法轮。

### 美术

- **材质**：默认日间，米白方格纸为底；未翻开格是贴在纸上的纸片（轻投影）；翻开后露出方格纸。夜间为同一材质的「深夜台灯」：暖棕纸面、降低亮度、左上角台灯光晕。
- **颜色**：成员一切颜色从官方**代表色**派生（灯 `#77BBDD`、爱音 `#FF8899`、乐奈 `#77DD77`、爽世 `#FFDD88`、立希 `#7777AA`，均已对照 BanG Dream! Wiki 核实）；全局强调色用**乐队色** `#3388BB`。纸面上的文字与数字用「深墨」变体，对纸面对比度 ≥ 4.5:1；夜间用提亮变体。
- **数字**：1 灯、2 乐奈、3 爱音、4 立希、5 爽世（深墨变体）；6–8 用中性墨色。
- **雷**：画成铅笔乱线团的「心结」；踩中的那颗变红。规则与文案仍叫「雷」。
- **旗**：米色创可贴。**护盾**挡下的雷：爽世代表色（淡黄）创可贴。
- **提示高亮**：可连开 / 可收雷的数字与目标格用荧光笔笔触（连开 = 当前领队代表色，收雷 = 金色）。
- **决斗领地**：玩家 = 铅笔石墨灰，灯 AI = 灯代表色蓝；技能高亮仍用领队代表色。
- **字体**：全局霞鹜文楷（OFL）。构建时从源码字符串自动生成子集；测试检查任何界面字符串都不缺字。
- **头像**：代表色纸片圆形 + 一个文楷汉字（灯、爱、爽、立、乐）；名字后附罗马字小字。顶栏的「M」头像换成迷你图标。
- **图标**：方格纸圆角方块 + 五色手写「!!!!!」（乐队顺序：灯、爱音、乐奈、爽世、立希）+ 左下角斜贴创可贴；原创 SVG，导出 1024px PNG。
- **曲目选择**：手写**歌单**，点开后按「经典 / 决斗」分组列出七首。

### 文案

- 去掉技术口吻：游戏内 `egoist/mygo Native UI` 等字样删除；README 删去图形 API / `cgo` 行与英文摘要的技术段，底部只留三条运行命令；「零官方素材」段改写为「原创绘制 + OFL 字体」。
- README 原有的梗一条不少；成员称号等梗一字不改。
- 「百万格决斗」的说法全部删除；决斗台词不得写死棋盘尺寸或时长。
- **最终文案由 hydrogen 定稿**：这里只产出一份文案清单（位置、现文案、改动原因、约束），核对后交 hydrogen；《春日影》的副标题（草案「解不完的心结」）也在清单里。

- 不做解锁进度，七首都可直接选。

## Implementation Decisions

- **组件复用**：能用 egoist/mygo 的组件就用（头像用 `ui.Avatar` 覆盖颜色、进度用 `ui.Progress` / `ui.Meter`、歌单用 `ui.Popover`）；只在框架画不出的视觉上自绘，且自绘处保留组件语义（角色、数值、键盘与焦点）。格子与决斗画布没有对应组件，继续自绘。
- **主题令牌**：所有颜色走一处调色板（日 / 夜两套），按语义命名（纸面、纸片、墨、乐队色、各成员代表色及其深墨 / 提亮变体）；界面代码不再出现裸 hex。
- **玩法字段**：曲目数据新增「玩法（经典 / 决斗）」「决斗时长」「AI 节奏」，取代现在四处 `ID == "duel"` 与 `ID == "hard"` 的特判。
- **画布复用**：大棋盘经典曲目复用决斗画布的平移、缩放、悬停提示、涟漪与震屏；只是不画 AI 领地。
- **字体管线**：一个生成步骤从 Go 源码收集界面字符串 → 子集化霞鹜文楷 → 嵌入；测试断言所有字符串字符都在子集里。
- **截图**：`snapshot_test.go` 在设置 `MYGO_SNAPSHOT_DIR` 时无头渲染样张 / README 截图，CI 中自动跳过。

## Testing Decisions

- 沿用现有确定性 RNG 与 `ui.NewTester` 测试；改名、改尺寸会让约 40 处测试引用失效，随工单一起更新。
- 新增：颜色只来自调色板（无裸 hex）、深墨数字对比度 ≥ 4.5:1、字体子集不缺字、七首曲目参数与玩法字段、春日影演出只在《春日影》决斗失败时触发。

## Out of Scope（之后的玩法与平衡轮）

- **重力值的用途**：目前只显示、不影响任何东西（计划中的「重力 ≥ 80 解锁大招」未实现）。本轮只按新风格重画，留作玩法轮第一项。
- 整套技能微调；按成员分别模拟乐队模式通关率（关注爽世护盾在大棋盘上是否过强）。
- 爽世在决斗中按 E 会消耗充能的既有不一致。
- 任何官方立绘、Logo、音频。

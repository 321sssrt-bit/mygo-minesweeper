# 美术定调为「灯的笔记本」，并放宽零外部素材约束

项目原本梗足而打磨不足：沿用开发者仪表盘式的深海军蓝，成员色各处自挑、与官方代表色不符，文案带着技术演示腔，与作品「迷子」的基调脱节。我们决定以作品简介为锚，把整体美术定为「灯的笔记本」：默认亮色的米白方格纸，未翻开格是贴在纸上的小纸片，旗是创可贴，雷画成一团铅笔乱线的「心结」（「踩雷」即戳中某人的心结，与「为什么要演奏春日影」名场面同构；插旗即在心结上贴一张创可贴）；夜间模式是同一套材质的「深夜台灯下的笔记本」，而不是另一套视觉语言。为此放宽「界面全部由原生代码实时绘制」的约束，允许嵌入一款 OFL 授权字体（霞鹜文楷，按实际用字子集化）和原创 SVG 小道具；官方立绘、Logo、音频仍然一律不打包。

## Considered Options

- **放学后的天空**（淡蓝水彩、大留白）：贴近宣传图，但与扫雷网格没有结构上的呼应，也缺少角色道具可讲的故事。
- **RiNG 暖黑舞台**（炭灰、追光）：能保留暗色玩家习惯，但仍是「酷炫暗黑」路线，与「迷子、笨拙、手写」的基调相悖；作为夜间版本也会造成两套视觉语言并存、美术工作量翻倍。

## Consequences

- 成员的一切颜色表达只从官方**代表色**派生，乐队整体用**乐队色**做强调色；决斗中灯 AI 用灯的代表色蓝，玩家用铅笔石墨灰（「你和灯在同一页纸上抢着写」）。
- 这是纯视觉与文案语气的改动：玩法规则、计分与梗的数量冻结；成员称号等梗一字不改。
- README 去掉技术口吻（只在底部保留最简运行命令），但**原有的玩梗内容全部保留**；「零官方素材」声明需改写为「原创绘制 + OFL 字体」的准确表述。
